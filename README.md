# Rig.Red – Hardware & Software Projects

Welcome to the repository for my personal blog and project portfolio, hosted at [**0xcats.net**](https://0xcats.net).  
This site serves as a digital journal and showcase for my work in hardware engineering, reverse engineering, and retro computing.

---

## 🔍 About This Site

This website is a collection of deep-dive articles, project logs, and resources at the intersection of hardware and software. The content is built around a few core passions:

### 🛠️ Hardware Engineering & Reverse Engineering

- Designing custom PCBs
- Analyzing undocumented hardware
- Solving complex technical challenges

### 🧩 Retro Computing

- Preserving and extending the life of vintage hardware
- Creating custom daughterboards for legacy CPU sockets
- Archiving rare drivers and BIOS files

### 💻 Low-Level Software & Firmware

- Developing firmware and system-level software
- Projects with `coreboot` and embedded Linux
- Writing tools to interface directly with hardware

---

## ⭐ Featured Content

You can explore the site through its main sections:

- **Posts**  
  In-depth technical articles on topics like the Kunpeng 916 CPU architecture, reverse-engineering IDE controller cards, and overclocking on Linux.

- **Projects**  
  A portfolio of custom hardware, including:
  - `SIMMBA` – SIMM Memory modules  
  - `Slotcat` – CPU Slot Key Adapter  
  - Custom Socket 5/7 Daughterboards

- **Software Archive**  
  A curated collection of rare drivers and BIOS files, including:
  - Legacy graphics drivers (e.g., ATI FireGL)
  - Motherboard firmware and utility disks
